# Решение: Кодирование текста в аудио

## Описание алгоритма

Реализован алгоритм кодирования текста в аудио на основе частотной модуляции (FSK - Frequency-Shift Keying):

### Кодирование
1. **Текст → Бинарная строка**: Текст конвертируется в UTF-8 байты, добавляется заголовок с длиной и контрольной суммой
2. **Бинарная строка → FSK сигнал**: Каждый бит кодируется в синусоиде определенной частоты:
   - '0' → 800 Hz
   - '1' → 1000 Hz
3. **FSK сигнал → WAV файл**: Сигнал сохраняется в формате PCM 16-bit, mono, 44100 Hz

### Декодирование
1. **WAV файл → FSK сигнал**: Чтение аудио данных
2. **FSK сигнал → Бинарная строка**: Анализ спектра для определения частот
3. **Бинарная строка → Текст**: Извлечение данных, проверка контрольной суммы, декодирование UTF-8

## Особенности реализации

- **Синхронизация**: Добавлены синхронизационные биты для надежного декодирования
- **Контрольная сумма**: Проверка целостности данных
- **UTF-8 поддержка**: Полная поддержка кириллицы и специальных символов
- **Устойчивость к шумам**: FSK модуляция обеспечивает хорошую устойчивость к помехам
- **Адаптивная длительность**: Поддержка строк различной длины

## API

- `POST /encode` - кодирование текста в WAV
- `POST /decode` - декодирование WAV в текст
- `GET /ping` - проверка работоспособности
