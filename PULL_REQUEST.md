# Pull Request: dev → main

## Описание изменений

В ветке `dev` реализован полнофункциональный веб-сервис для кодирования и декодирования текста в аудио с использованием FSK (Frequency-Shift Keying) модуляции.

## Основные изменения

### ✅ Реализованные функции:
- **POST /encode** - кодирование текста в WAV файл
- **POST /decode** - декодирование WAV файла в текст
- **GET /ping** - проверка работоспособности сервиса

### 🔧 Технические особенности:
- **FSK кодирование**: Каждый бит представлен определенной частотой (800 Hz для '0', 1000 Hz для '1')
- **Синхронизация**: Добавлены синхронизационные биты для надежного декодирования
- **Контрольная сумма**: Проверка целостности данных
- **UTF-8 поддержка**: Полная поддержка кириллицы и специальных символов
- **Устойчивость к шумам**: FSK модуляция обеспечивает хорошую устойчивость к помехам

### 📊 Результаты тестирования:
- ✅ 100% успешных тестов
- ✅ Поддержка кириллицы ("Привет мир!")
- ✅ Поддержка специальных символов ("!@#$%^&*()")
- ✅ Поддержка длинных строк (до 50 символов)
- ✅ Соответствие требованиям по формату аудио (PCM 16-bit, mono, 44100 Hz)
